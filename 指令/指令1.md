## 前置说明

| 08-桌面环境SDK | libkysdk-soundeffects.so | C++ | amixer 音量 |
| 08-桌面环境SDK | libkysdk-notification.so | C++ | 通知弹窗 |
| 08-桌面环境SDK | libkysdk-appmanager.so | C++ | 应用启动/管理 |
| 08-桌面环境SDK | libkysdk-thememanager.so | C++ | 亮色/暗色主题 |

| 09-AI-SDK | libkysdk-coreai-vision.so | C | OCR 文字识别 |

### 步骤 1.2：实现 `src/sdk/base.py` — ctypes 基础工具

```python
"""ctypes .so 加载器基类"""
import ctypes
import ctypes.util
from pathlib import Path

def load_library(soname: str, fallback_paths: list[str] = None):
    """加载 .so 库，支持 soname 自动查找和 fallback 路径"""
    path = ctypes.util.find_library(soname)
    if path:
        return ctypes.CDLL(path)
    for fp in (fallback_paths or []):
        p = Path(fp)
        if p.exists():
            return ctypes.CDLL(str(p))
    raise FileNotFoundError(f"找不到库: {soname}")
```

## DBus 路径验证清单

以下 DBus 接口需要在 Kylin 系统上使用 `busctl` 或 `qdbusviewer` 验证：

| 功能 | 可能的 DBus 路径 | 验证命令 |
|------|-----------------|---------|
| 音量控制 | `org.pulseaudio.Server` 或 PipeWire | `pactl list cards` |
| 亮度控制 | `org.gnome.SettingsDaemon.Power.Screen` | `gdbus introspect --session --dest org.gnome.SettingsDaemon.Power` |
| WiFi 开关 | `org.freedesktop.NetworkManager` | `nmcli radio wifi on/off` |
| 蓝牙开关 | `org.bluez` | `bluetoothctl power on/off` |
| 通知 | `org.freedesktop.Notifications` | `notify-send "test" "hello"` |
| 截图 | `org.gnome.Shell.Screenshot` | gnome-screenshot 的 DBus API |
| 壁纸 | `org.kde.plasmashell` | 取决于 Kylin 桌面环境版本 |
| 主题 | `org.ukui.SettingsDaemon` | UKUI 桌面特有 DBus |
