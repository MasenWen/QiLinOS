# 项目中使用了 Shell Command 的文件

共发现 **7 个文件**使用了 shell 命令执行能力，全部通过 Python `subprocess` 或 `asyncio.subprocess` 模块实现。

---

## 1. 核心 Bash 执行工具

### [src/tools/bash_tool.py](src/tools/bash_tool.py)

**用途**：开发智能体的通用 Bash 执行工具，供 Agent 调用

```python
result = subprocess.run(
    cmd, shell=True, check=True, text=True, capture_output=True
)
```

- `shell=True`：直接执行任意 shell 命令字符串
- `capture_output=True`：捕获 stdout/stderr
- 有 `CalledProcessError` 和通用异常的错误处理
- 是项目中最核心的 shell 命令执行入口，Agent 的 "程序员" 节点通过此工具执行终端命令

## 2. MCP 服务相关

### [mcp_host.py](mcp_host.py)

**用途**：MCP 主进程启动器，fork 子进程

```python
return subprocess.call(cmd)
```

- 调用外部 Python 脚本作为子进程
- 简单的同步调用，返回退出码

### [mcp_server/server/kylin_server.py](mcp_server/server/kylin_server.py)

**用途**：Kylin Linux 桌面控制服务

**异步执行**（主函数，带超时控制）：
```python
proc = await asyncio.create_subprocess_exec(
    *cmd,
    stdout=asyncio.subprocess.PIPE,
    stderr=asyncio.subprocess.PIPE,
    env=env,
)
# 逐行读取输出，asyncio.wait_for 超时控制
await asyncio.wait_for(reader(), timeout=timeout)
```

**同步执行**（安全命令如 amixer）：
```python
p = subprocess.run(cmd, check=False, stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True, env=env)
```

- 执行 xdotool、amixer 等 Linux 桌面控制命令
- 异步 + 超时控制，避免命令卡死
- 有 ANSI 转义字符清理

### [mcp_server/server/local_server.py](mcp_server/server/local_server.py)

**用途**：本地 GPU 监控服务

```python
result = subprocess.run(
    ["nvidia-smi", "-q", "-d", "MEMORY"],
    stdout=subprocess.PIPE,
    stderr=subprocess.STDOUT,
    text=True
)
```

- 调用 `nvidia-smi` 查询 GPU 显存使用情况
- 解析 FB Memory Usage 信息

## 3. UI 自动化

### [src/tools/UI_assistant.py](src/tools/UI_assistant.py)

**用途**：Linux 桌面应用的启动与操控

```python
process = subprocess.Popen(
    command,
    shell=True,
    stdout=subprocess.PIPE,
    stderr=subprocess.PIPE,
    start_new_session=True  # 创建新会话避免阻塞
)
```

- `start_new_session=True`：使子进程脱离当前会话，独立运行
- 用于在 Kylin Linux 桌面上启动 GUI 应用程序（浏览器、办公软件等）
- 先尝试非阻塞启动，再检查进程状态

## 5. 间接使用（通过 import os / exec 等）

以下文件使用了 `import os` 或 `exec()`，但主要用于环境变量读取、路径操作等，**并非执行外部 shell 命令**：

## 总结

| 文件 | 执行方式 | 风险等级 | 说明 |
|------|---------|---------|------|
| `src/tools/bash_tool.py` | `subprocess.run(shell=True)` | ⚠️ 高 | 通用 shell 执行，Agent 可用 |
| `mcp_server/server/kylin_server.py` | `asyncio.subprocess` + `subprocess.run` | ⚠️ 高 | Linux 桌面命令执行 |
| `src/tools/UI_assistant.py` | `subprocess.Popen(shell=True)` | ⚠️ 高 | 桌面应用启动 |
| `mcp_host.py` | `subprocess.call()` | 🔶 中 | 子进程启动 |
| `mcp_server/server/local_server.py` | `subprocess.run()` | 🔒 低 | 固定命令 nvidia-smi |
| `src/tools/ocr_tool.py` | `subprocess.run()` | 🔒 低 | 固定命令 ocr_tool |
| `test/test_ocr.py` | `subprocess.run()` | 🔒 低 | 测试用固定命令 |

**高风险项**（3个）都涉及 `shell=True` 或动态命令执行，需要关注命令注入风险。
