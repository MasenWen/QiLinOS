# Evaluation datasets

This directory contains only the prepared datasets used by the stable memory
pipeline evaluations.

- `os_agent_memory_query_benchmark_v3.1`: the retained 47-event and 530-query
  benchmark bundle.
- `os_agent_memory_query_benchmark_official_1000_v1_20260806`: the prepared
  200-precedent and 800-query formal benchmark. The duplicate transfer ZIP is
  intentionally omitted.

The larger v5.3 source dataset remains outside the repository. These prepared
datasets are evaluation inputs, not runtime user memory.
